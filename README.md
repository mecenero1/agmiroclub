# Le club 55

Сайт магазина Le club 55 — high club standarts. Дроп 01: Azul T-Shirt и LeClub55 Card Holder (XX Deck, UKC).

Один файл `index.html` и папка `img/`. Ничего собирать не нужно: загрузите оба на хостинг или включите GitHub Pages.

## Что внутри

- Магазин в одном блоке: переключатель «Футболка / Картхолдер», фон меняется под товар и цвет.
- Футболка поворачивается в 3D (спереди / сзади), картхолдеры лежат колодой и листаются свайпом.
- Кнопка house включает deep house, сгенерированный прямо в браузере (Web Audio), фон пульсирует в такт.
- Корзина, оформление заказа с доставкой СДЭК (пункт выдачи или курьер), маска телефона, проверка полей.
- Нижнее меню на телефоне, лукбук на весь экран, вкладки «Доставка / Оплата / Возврат».
- Анимации только на transform и opacity, без размытия фона и перерисовки текста: держит 60 fps на телефоне.

## Настройки

Всё в начале `<script>` в `index.html`.

```js
const CONFIG = {
  orderEndpoint: '',      // адрес вашего обработчика заказов (POST, JSON)
  telegram: 'leclub555'   // куда уходит заказ, пока orderEndpoint пустой
};
```

- **Заказы.** Пока `orderEndpoint` пустой, оформленный заказ собирается в текст и отправляется в Telegram @leclub555. Если у вас есть сервер (ЮKassa, СДЭК), впишите его адрес: сайт отправит туда JSON с товарами, получателем и доставкой.
- **Остатки и размеры.** В объекте `PRODUCTS`: `sizes` у футболки (`false` — размера нет) и `stock` у каждого цвета картхолдера.

## GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`. Через минуту сайт откроется по адресу `https://<логин>.github.io/leclub55/`.
